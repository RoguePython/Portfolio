# Release Notes v1.3.0

## Version 1.3.0 - 2026-06-29

### Summary
Added a Prompt Games hub with three vanilla JS browser games, replacing the standalone Pipe Game folder.

### Added
- **Games hub** (`games/`) — central menu linking to all prompt games
- **Pipe Flow** (`games/pipe-flow/`) — pipe rotation puzzle with scoring
- **Snake** (`games/snake/`) — classic snake with themes, settings, pause, and high scores
- **Minesweeper** (`games/minesweeper/`) — classic difficulties, timer, flags, chord reveal, and best times
- Hub and game thumbnails in `assets/images/`

### Changed
- Portfolio project card updated from single Pipe Flow entry to Prompt Games collection
- README architecture and featured projects document all three games
- Removed legacy `Pipe Game/` folder (superseded by `games/pipe-flow/`)

### Games

| Game | Path | Highlights |
|------|------|------------|
| Pipe Flow | `/games/pipe-flow/` | Grid puzzle, level progression, move-based scoring |
| Snake | `/games/snake/` | Canvas animation, 4 themes, grid/controls settings, Esc pause |
| Minesweeper | `/games/minesweeper/` | Beginner/Intermediate/Expert, safe first click, chord, localStorage best times |
