# Release Notes v1.4.0

## Version 1.4.0 - 2026-06-30

### Summary
Added **Tetra Blocks**, a guideline-style falling-blocks game, as the fourth title in the Prompt Games collection.

### Added
- **Tetra Blocks** (`games/tetra-blocks/`) — canvas-based falling-blocks puzzle
  - 7-bag piece randomizer
  - 3-piece next queue with aligned preview panel
  - SRS wall-kick rotation
  - Ghost piece and hard drop
  - Simultaneous multi-line clear animation
  - Guideline scoring, level progression, and localStorage high score
- Game documentation at `games/tetra-blocks/README.md`
- Hub thumbnail `assets/images/tetra-blocks.png`

### Changed
- Games hub intro and card list include Tetra Blocks
- Portfolio Prompt Games project card blurb updated
- README featured projects table and architecture tree document Tetra Blocks
